# 🌼 Flores amarillas — 21 de septiembre

Página romántica interactiva hecha con HTML, CSS y JavaScript.

## Publicarla con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y `README.md`.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama **main** y la carpeta **/(root)**.
6. Pulsa **Save**.

Después de unos momentos GitHub Pages te mostrará la dirección pública de tu página.

## Personalizar el mensaje

En `index.html`, busca `<div class="letter">` y cambia los tres párrafos por el mensaje que quieras dedicarle.
